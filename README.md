# Maple Portfolio

Free, open-source, read-only portfolio analytics for Canadian investors through ChatGPT.

**Status:** planning and development; not yet published in the ChatGPT directory.

This project is independent of Wealthsimple and is not affiliated with or endorsed by Wealthsimple or OpenAI.

The first version will accept supported CSV exports; it will not request brokerage passwords, connect to undocumented brokerage APIs, execute trades, or provide personalized investment advice.

See the planning pull request for detailed architecture, Codex instructions, and milestone issues.
