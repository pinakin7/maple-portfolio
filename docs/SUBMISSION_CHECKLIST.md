# OpenAI plugin review readiness (living checklist)

Before submission, independently verify current OpenAI documentation and policy:
- [ ] Public HTTPS remote MCP endpoint with verified domain and authenticated tool/session design where needed
- [ ] Correct current app/plugin packaging, metadata and icons
- [ ] Embedded UI renders safely in supported ChatGPT clients
- [ ] Publisher/developer verification complete
- [ ] Accurate tool descriptors, permissions, deletion controls and user-facing privacy disclosures
- [ ] Working privacy policy, terms and support contact
- [ ] No misleading Wealthsimple affiliation or unsupported financial advice
- [ ] Positive and negative review test cases and demo assets as currently required
- [ ] Automated tests, security review and independent reproduction completed
- [ ] Runtime budget and monitoring configured
- [ ] Explicit maintainer approval to submit

No directory approval or timeline is guaranteed. No submission is authorized by this checklist.
